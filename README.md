# SPSS Excel Report Extractor（SPSS 輸出表格整理）

這是一個**公開展示／教學用版本**，由先前在 Google Colab 上進行的自主學習原型整理而來。目的在於減少從 SPSS 匯出的 Excel 報表中，重複尋找欄位、抄錄數值與整理表格的工作。

> **重要區分**：原始原型曾配合特定研究表格擷取資料並套入 LaTeX 模板；目前的 `main.py` 經重新整理，保留關鍵字定位、上下儲存格分析、2／6 筆候選資料形態辨識及報表輸出概念，並加入 `.xlsx` 支援、命令列與人工複核提示。**本版本不是原始研究統計結果的重製，也尚未用當年的真實研究資料驗證等價性。**

## 開發動機

處理 SPSS 匯出的 Excel 報表時，我需要反覆尋找「百分比」、「次數」、「顯著性。」、「Exp(B)」、「上界」、「下界」等欄位。由於表格格式與資料位置不固定，單純指定儲存格座標並不方便，因此嘗試將「搜尋關鍵字 → 判斷欄位附近的資料排列 → 擷取並檢查筆數 → 整理輸出」寫成程式。

## 展示功能

- 在 Excel 工作表內搜尋指定關鍵字，並記錄每次出現的位置
- 擷取關鍵字下方有限範圍內的非空儲存格，同時保留上方儲存格資訊供核對
- 將 2／6 筆資料視為候選欄位型態；其他情況標示 `review_needed`，**不自動宣稱數值正確**
- 輸出 CSV、JSON、簡單的 LaTeX 表格，以及需人工檢查清單
- 支援 `.xlsx`，也可透過 `xlrd` 讀取舊版 `.xls`

## 如何使用

需要 Python 3.10 以上：

```bash
python -m pip install -r requirements.txt
python main.py --input examples --output output
```

程式預設讀取 `examples/`，結果輸出至 `output/`。附帶的 `examples/sample_spss_export.xlsx` 是**完全虛構的示範資料**，不含任何真實研究資料或個資。

輸出項目：

- `output/extracted.csv`：結構化擷取資料
- `output/extracted.json`：詳細資訊，包含原始資料形態
- `output/report.tex`：簡化 LaTeX 表格示例，需另有 LaTeX 環境才能編譯
- `output/needs_review.txt`：擷取結果可能不完整的提示

測試（使用人工建立的範例表格）：

```bash
python -m unittest discover -s tests -v
```

## 專案流程

`Excel 匯出表格` → `關鍵字比對` → `判斷欄位區塊（2／6 筆）` → `整理資料` → `輸出與人工核對`

## 限制與注意事項

1. 僅擷取 **SPSS 已經計算並匯出的數值**，不是自行實作 SPSS 的統計演算法。
2. 表格若有合併儲存格、跨欄位資料、不同上／下排列方式，可能需要人工調整提取邏輯。
3. `candidate` 只代表筆數符合目前規則，不表示分類、變項意義、統計數值或配對一定正確。
4. 此版本的通用 LaTeX 表格與原始專用研究模板不同，不應直接拿來重製原報告。
5. 沒有附上原始資料、受試者資料、原 Colab 個人連結或研究報告內容。

更多版本差異請見 [`PROVENANCE.md`](PROVENANCE.md)，原始程式的去識別化邏輯節錄收錄於 `archive/`。
